# 因子方法论

本文档记录第一版基础因子系统的因子来源、预处理流程和数据泄露控制原则。

## 因子来源

- 估值因子：`ep`, `bp`, `ps_inverse`
- 规模因子：`size_factor`
- 流动性因子：`turnover_factor`, `amount_factor`
- 动量因子：`momentum_1m`, `momentum_3m`
- 风险因子：`volatility_6m`

## 因子预处理流程

1. 缺失值填补：先按 `date + industry` 分组使用组内中位数填补，再按 `date` 使用当月全市场中位数填补。
2. 缩尾：按每月横截面执行 1%-99% 分位数缩尾。
3. 标准化：按每月横截面执行 z-score 标准化。
4. 标签：`return_next` 为下月收益，仅作为目标变量。

## 数据泄露控制

- 因子只使用当期及历史信息。
- `return_next` 只作为目标变量，不参与因子预处理和打分。
- 动量和波动率使用 `shift` 方式排除当前月或未来信息。

## 说明

- 当前版本为第一版基础因子系统。
- 后续可加入财务质量、成长性、行业/市值中性化和机器学习模型。

## 因子有效性检验

### RankIC

- 每个月计算因子横截面排序与下月收益 `return_next` 的 Spearman 相关系数。
- Mean IC 衡量因子的平均预测方向。
- ICIR 衡量 IC 的稳定性。
- t-stat 衡量统计显著性。

### 分组收益

- 每个月按因子值从低到高分成五组 `Q1`-`Q5`。
- 观察各组下月平均收益是否具有单调性。

### 多空收益

- `long_short_return = Q5 - Q1`。
- 当前版本只用于因子研究统计，不等同于真实可交易策略收益。
- 后续回测模块会进一步纳入换手率、交易成本和组合约束。

### 数据泄露控制

- 因子在 t 月形成。
- `return_next` 是 t+1 月收益，只作为检验标签。
- 因子检验不能使用未来收益参与因子标准化或打分。
